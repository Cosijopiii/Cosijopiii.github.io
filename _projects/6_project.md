CGP-NAS explores how Cartesian genetic programming and evolutionary optimization can automatically design convolutional neural networks that balance accuracy and complexity.

## Papers

- **CGP-NAS: Real-based solutions encoding for multi-objective evolutionary neural architecture search** (2022). Introduces a real-based representation and multi-objective search for image classification architectures. [Read the paper](https://doi.org/10.1145/3520304.3528963).
- **Continuous Cartesian Genetic Programming based representation for multi-objective neural architecture search** (2023). Develops two CGP-NAS variants with different search-space granularities and compares multi-objective search techniques. [Read the paper](https://doi.org/10.1016/j.asoc.2023.110788) or the [preprint](https://arxiv.org/abs/2306.02648).

[View the code on GitHub](https://github.com/Cosijopiii/CGPNAS).
